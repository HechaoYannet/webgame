# 《张强宿舍大逃杀》信息架构重构版

## 核心设计理念

- **信息密度高**：模拟真实互联网，每个平台都有大量无关、半相关、真正相关的信息。
- **线索埋藏深**：关键信息不会以“看这里”的形式出现，而是分散在多个角落，需要玩家自己建立关联。
- **红鲱鱼**：设计多个看似重要、实际与主线无关（或只是侧面补充）的线索，增加辨识难度。
- **提示分级**：玩家卡关时，系统通过“主角内心独白”给予模糊提示，不直接给答案。

## 五、提示系统设计

- “李桥瑞说密码是‘那个日子’……哪个日子？他说我看了朋友圈就懂了。朋友圈里他发了终末地公测资格，那公测是哪天？”

**卡在绿中内部系统密码时**：
- “张强是校长，他的密码会是什么？校长寄语里面好像有句话……‘我的小目标是先挣一个亿’……那密码会不会是‘yigeyi’？”

**卡在实验室后台密码时**：
- “论文里有基金号，公众号解读里说密码是基金号后6位……基金号是2025YFC0123456……”

### 5.2 触发时机

内心独白在玩家触发特定条件后出现：

- 玩家在某个页面停留超过1分钟且未操作
- 玩家多次尝试输入错误密码（3次后）
- 玩家询问特定角色（微信聊天中主动问问题）

## 七、总结

重构后的信息库具有以下特点：

- **量大**：微信14个联系人、3个群、50+条朋友圈、8个公众号；QQ 7个聊天窗口、空间、群文件；浏览器10+网站、30+页面。
- **分散**：关键线索分散在不同平台、不同日期、不同形式。
- **交叉验证**：同一事实需要多个信息源互相印证，例如李桥瑞失联：群聊中有人说他被车接走、班主任说回家了、李桥瑞妈妈说没去接、QQ聊天记录显示计划潜入。
- **红鲱鱼**：大量看似重要但实际无关的信息。
- **提示分级**：内心独白、角色对话、系统提示，逐渐递进。

这样玩家就有了“找信息”的感觉，而不是被直接喂信息。
